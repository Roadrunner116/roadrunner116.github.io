FamilyPlanner – Privacy policy

Last updated: 2026-11-19

Who operates FamilyPlanner

FamilyPlanner is a private, non-commercial application operated by one household for its own members. It is not offered to anyone else.

Which Google data is accessed

With the consent of the signed-in user, FamilyPlanner reads calendar events from Google Calendar using the read-only scope https://www.googleapis.com/auth/calendar.readonly. No other Google data is accessed.

How the data is used

Calendar events are used only to show upcoming appointments on the household's wall display and in the household's own browser views. Events marked private are shown only as "busy"; their details are not stored.

Where the data is stored

Calendar data is stored only on hardware in the household or on servers within the European Union. It is not sold, shared with third parties, used for advertising, or used to train machine learning models.

Retention and deletion

Cached calendar data is replaced on every synchronisation. Access can be revoked at any time at myaccount.google.com/permissions; the cached data is then deleted from the planner.

Compliance

FamilyPlanner's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
